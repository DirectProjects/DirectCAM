# Modyfikacja bibliotek USB / USB library modification

APK i pasujący pakiet bibliotek z instrukcją znajdują się w [plikach DirectCAM 0.4.7-test](https://directprojects.github.io/DirectCAM/legal.html).

Pobierz DirectCAM-0.4.7-library-kit.zip. Zawiera komplet źródeł bibliotek natywnych USB, binarną aplikację i narzędzie do przebudowania/podmiany bibliotek oraz podpisania własnego APK. Otwórz README.md wewnątrz pakietu. Źródła własnego kodu aplikacji nie są wymagane przez tę procedurę.

Download the matching library kit from the release above and follow its README.md. It supplies corresponding native sources, the binary app and a rebuild/relink/sign tool. Publisher signing keys and original app source are not required.
